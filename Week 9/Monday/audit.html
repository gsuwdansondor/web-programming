01 / BASELINE AUDIT

Step 1: Before Audit (Initial Score & Issues)

Accessibility Score: 96 / 100

Running an initial Chrome Lighthouse accessibility audit on our team project page flagged the following items:

  • Elements use prohibited ARIA attributes (Scored): An aria-label was placed on a generic <div id="board"> element without a valid semantic ARIA role.
  • <video> elements contain a <track> element with [kind="captions"] (Unscored): The embedded group presentation video lacked closed captions.
  • Keyboard Navigation & Form Labels (Manual Checks): Keyboard users lacked a skip-to-content shortcut, and form selects/buttons lacked explicit associations or standard types.

02 / IMPLEMENTATION

Steps 2 & 3: What We Changed (Code Fixes)

We implemented 4 key accessibility improvements across our HTML and companion caption files:

1. Fixed Prohibited ARIA Attribute

Added role="group" to the game board container so screen readers correctly process the aria-label.

Before
<div id="board" class="board" aria-label="Memory cards"></div>
After
<div id="board" class="board" role="group" aria-label="Memory cards"></div>

2. Added Video Captions Track

Created a WebVTT file (captions.vtt) and attached a caption track to the presentation video.

Before
<video id="presentation-video" controls>
  <source src="MemoryMatch.mp4" type="video/mp4">
</video>
After
<video id="presentation-video" controls>
  <source src="MemoryMatch.mp4" type="video/mp4">
  <track kind="captions" src="captions.vtt" srclang="en" label="English" default>
</video>

3. Added Skip Navigation Link

Added a focusable skip link at the top of the body for keyboard-only users.

Before
<body>
  <header>...</header>
  <main>...</main>
After
<body>
  <a class="skip-link" href="#main-content">Skip to main content</a>
  <header>...</header>
  <main id="main-content">...</main>

4. Form Labels & Button Types

Explicitly linked form labels and added type="button" to all interactive game controls.

Before
<button id="start">Let's play</button>
After
<button id="start" type="button">Let's play</button>
